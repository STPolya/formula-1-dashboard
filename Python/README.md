# Formula-1 Dashboard (Python)

Интерактивная Python версия дашборда по Формуле‑1.

Приложение получает данные из SQLite, выполняет
SQL-запросы и отображает результаты на страницах.

## Возможности

- Четыре страницы: история чемпионата, сезон 2021,
  детализация по пилотам и командам.
- Выбор периода в историческом разделе.
- Выбор пилота и команды на соответствующих страницах.
- Карточки ключевых показателей.
- Интерактивные графики и таблицы.
- Просмотр динамики очков и результатов Гран-при.

## Технологии

| Инструмент | Назначение |
|---|---|
| Python | Логика приложения |
| SQLite и SQL | Хранение данных и аналитические расчёты |
| sqlite3 | Подключение к SQLite из Python |
| pandas | Получение результатов запросов в DataFrame |
| Plotly | Интерактивные графики |
| Streamlit | Страницы, фильтры, карточки и навигация |

Основные аналитические расчёты выполняются в SQL.
pandas используется для получения и передачи результатов визуализациям.

## Установка и запуск

Все команды выполняются из корня репозитория.

### 1. Создание окружения

```powershell
py -3.14 -m venv .venv
```


### 2. Установка зависимостей

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. Запуск приложения

```powershell
.\.venv\Scripts\python.exe -m streamlit run python/app.py
```

Откройте адрес, указанный в терминале, обычно:

```text
http://localhost:8501
```

Во время работы приложения терминал должен оставаться открытым.
Для остановки нажмите `Ctrl+C`.

## База данных

Приложение использует готовую базу:

```text
database/f1.db
```

Для обычного запуска пересоздавать её не нужно.
Исходные данные и код сборки находятся в папке `database`.

## Организация кода

- `app.py` — точка входа и навигация.
- `pages/` — интерфейс страниц и отображение результатов.
- `modules/queries.py` — SQL-запросы.
- Остальные модули — вспомогательные функции приложения.

Выбранные пользователем параметры передаются в SQL-запросы.
Полученные таблицы используются для построения графиков
и отображения метрик.
