# Formula-1 Dashboard (Power BI)

Версия аналитического дашборда по Формуле‑1,
реализованная в Power BI.

Источник данных: общая база SQLite.
Подключение выполняется через ODBC, подготовка данных в Power Query,
аналитические расчёты с использованием DAX.

## Содержимое

Четыре страницы дашборда:

- Исторический обзор чемпионата.
- Обзор сезона 2021.
- Детализация по пилотам.
- Детализация по командам.

На страницах представлены ключевые показатели, рейтинги,
турнирные таблицы, динамика очков и результаты этапов.

## Используемые инструменты

- **Power BI Desktop** — модель данных и визуализации.
- **Power Query** — получение и преобразование данных.
- **DAX** — меры и аналитические расчёты.
- **SQLite** — хранение данных.
- **SQLite ODBC Driver** — подключение к базе.

## Открытие отчёта

1. Скачайте репозиторий.
2. Откройте файл `.pbix` в Power BI Desktop.
3. Для просмотра сохранённых данных обновлять источник обычно не требуется.

Для обновления данных настройте подключение к SQLite.

## Подключение к базе

1. Установите SQLite ODBC Driver соответствующей разрядности.
2. Откройте в Windows «Источники данных ODBC» нужной разрядности.
3. Создайте пользовательский источник данных с именем:
   `F1 Dashboard Data`.
4. Выберите драйвер SQLite3.
5. Укажите полный путь к `database/f1.db` из скачанного репозитория.
6. Откройте отчёт в Power BI Desktop и нажмите «Обновить».
7. Если появится запрос учётных данных для обычной локальной базы,
   выберите «По умолчанию или настраиваемый».

Имя источника должно совпадать с используемым в Power Query:

    dsn=F1 Dashboard Data

При перемещении базы необходимо обновить путь в настройках ODBC.
Параметр пути к папке CSV больше не используется.

## Особенности

- Данные импортируются в модель Power BI.
- Изменения базы появляются в отчёте после обновления.
- Для обновления на другом компьютере требуется настроить ODBC.
- Инструкция относится к локальной работе в Power BI Desktop.
